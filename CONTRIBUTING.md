# Contributing

Thanks for helping improve this list. Please read the rules below before opening a pull request.

## What gets accepted

- **Established projects only.** The project must already be in real use and known in the geospatial community. Brand-new projects are not accepted, so please wait until it has an established user base.
- **AI projects** (including MCP servers and agent skills) are welcome, under the same condition: already used and known.
- **SaaS, PaaS and DaaS** entries must be open source. Closed-source commercial services are not accepted.
- **No paid listings.** We do not accept donations or payment to list a project.

## How to add an entry

1. Add one entry per pull request, in the section where it fits best.
2. Keep the existing format:

   ```
   * [Name](https://link) - Short description.
   ```

3. Keep the section in alphabetical order.
4. Check for duplicates before adding.
5. Write a plain, factual one-sentence description. No marketing language.
6. Link to the project itself: the repository or official site. The link must work.
7. Use a clear title, for example `Add <Name> to <Section>`.

## What gets closed

Pull requests are closed if the project is new, not open source (for SaaS, PaaS, DaaS), a paid or promotional listing, a duplicate, out of order, or does not follow the format above.
